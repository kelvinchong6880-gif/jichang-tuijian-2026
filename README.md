## 买机场前看这 5 点

这几项比宣传带宽更有参考价值，买任何一家之前都可以对照检查。

1. **线路类型**：IPLC、IEPL 是专线，BGP 更看重多线路调度，宣传要和实际节点对得上。
2. **节点倍率**：标称流量要除以倍率，才是真正能用的流量。
3. **付款周期**：第一次购买先选小额套餐，不要直接买多年或买断。
4. **备用方案**：主力之外可以准备一个不限时小包，临时故障时有替代。
5. **官网入口**：先通过可信入口确认官网，避免买到仿冒站点。
